# rename_cli

간단한 파일 이름 정리 CLI 도구.

폴더 내 파일을 정렬 기준으로 순차 번호(001_, 002_ ...)를 부여하여
예측 가능한 순서로 rename을 수행.

---

## 기능

- 폴더 내 파일 정렬 후 순차 번호 자동 부여
- 파일 이름 변경 전 정렬 처리 (예측 가능한 순서 보장)
- 이미 번호가 붙은 파일 자동 스킵
- rename 대상 파일 충돌 감지 및 스킵 처리
- 빈 디렉토리 안전 종료
- dry-run 모드 지원 (실제 변경 없이 미리보기)
- 실행 결과 요약 출력 (renamed / skipped / conflicts)

---

## 실행 예시

기본 실행:

python rename.py --path ./test

dry-run 실행:

python rename.py --path ./test --dry-run

---

## 동작 정책

1. 입력 경로는 반드시 존재하는 디렉토리여야 한다.
2. 파일만 대상으로 처리한다. (디렉토리 제외)
3. 이미 3자리 번호가 붙은 파일은 스킵한다.
4. rename 대상 파일명이 이미 존재할 경우:
   - rename 하지 않고 스킵한다.
   - conflicts 카운트를 증가시킨다.
5. 처리 대상 파일이 없으면 안전 종료한다.
6. 모든 실행은 요약을 출력한다.

---

## 실행 요약 형식

- 변경 완료(또는 예정)
- 스킵
- 충돌
